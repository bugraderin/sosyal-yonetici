# Sosyal Yönetici public information pages

Static public homepage, Terms of Service, and Privacy Policy pages for the local desktop app. These pages are used as the public URLs in the TikTok developer app configuration.

- Homepage: `/`
- Terms: `/terms/`
- Privacy: `/privacy/`

Review the policy text for accuracy before submitting the app for TikTok review. Do not publish credentials or access tokens here.
